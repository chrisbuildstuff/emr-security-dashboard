EMR Security Monitoring Dashboard - Healthcare IT & Cybersecurity Demo
Full-stack security monitoring dashboard for Electronic Medical Record (EMR) systems, demonstrating integration of Health IT and Cybersecurity principles for Canadian healthcare environments.

Features:
- Real-time security event monitoring and visualization
- SQL-based audit logging with PIPEDA/PHIPA compliance considerations
- User behavior analytics identifying suspicious activity patterns
- Interactive dashboard with charts, tables, and severity-based alerts
- RESTful API architecture with Python Flask backend
- React frontend with responsive design

Technologies: Python, Flask, SQLite, React, Recharts, Tailwind CSS

Built to demonstrate skills in healthcare IT systems security, Canadian privacy regulations, database design, and full-stack development for health IT roles.
